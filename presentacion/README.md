# Monitor de Calidad del Aire — Pitch web

Presentación web responsiva para la socialización del segundo corte del proyecto **Monitor de Calidad del Aire**.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido** de esta carpeta a la raíz del repositorio (`index.html`, `styles.css`, `script.js`, `assets/`, etc.).
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios. GitHub mostrará la URL pública cuando termine el despliegue.

## Uso durante la exposición

- Flechas derecha/abajo o `PageDown`: siguiente diapositiva.
- Flechas izquierda/arriba o `PageUp`: diapositiva anterior.
- Botón **Presentar**: pantalla completa.
- Haz clic en las evidencias para ampliarlas.
- En celular o tableta la presentación se reorganiza como una página vertical responsiva.

## Estructura

- `index.html`: contenido de las 5 diapositivas.
- `styles.css`: diseño blanco/azul y adaptación responsive.
- `script.js`: navegación, modo presentación y ampliación de evidencias.
- `assets/`: evidencias de casos de uso, historias, mockups y Jira.
- `guion-presentacion.md`: guía sugerida para una exposición de 3 a 5 minutos.
