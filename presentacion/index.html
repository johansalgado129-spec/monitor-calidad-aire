Monitor de Calidad del Aire

Aplicativo web en Python para consultar, interpretar y visualizar mediciones de calidad del aire en ciudades de Colombia.

Problema

Los datos existen, pero no siempre son fáciles de interpretar.

PM2.5, NO₂ y O₃ suelen presentarse con unidades, estaciones y periodos técnicos. El proyecto busca convertir esa información en una lectura clara, trazable y útil para un usuario no especializado.

Objetivo

Unificar consulta, interpretación y registro en una experiencia web.

El backend en Python consulta OpenAQ, valida datos y prepara la información para mostrar AQI EPA cuando aplique, referencia OMS por separado, gráficas e historial.

HU-MA-001 · Alta

Como usuario visitante, necesito seleccionar una ciudad y consultar su calidad del aire para conocer las condiciones reportadas.

HU-MA-003 · Media

Como usuario visitante, necesito visualizar gráficamente los resultados y consultar el historial para comparar la información.

HU-MA-004 · Media

Como administrador, necesito una vista restringida para revisar y gestionar el historial del aplicativo.
